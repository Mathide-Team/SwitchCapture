# switch-capture

Orchestrateur de capture réseau pour switches HPE Comware
(5130/5140/5510/5520), avec CLI et interface graphique GTK4.

Dépôt importé depuis les archives de livraison du projet — le code arrive
sur `main` uniquement via des PR depuis la branche `dev` (voir le
garde-fou d'intégration dans `.github/workflows/guard-main.yml`).

Le contenu complet du projet est importé via la première PR `dev -> main`.
